Quick Start

几行代码即可接入

模型内嵌、零外部文件依赖；首次构建需下载权重（不随仓库分发）。

// FaceEngine — 基础管线（检测 + 3D 网格 + 语义分割）
use face_core::prelude::*;
use face_core::inference::EngineConfig;

let config = EngineConfig::default();
let mut engine = FaceEngine::new(config)?;
let image  = engine.load_image("face.jpg")?;
let result = engine.analyze(&image)?;
for face in result.faces {
    println!("bbox={:?}, conf={:.2}", face.face.bbox, face.face.confidence);
}

// FaceAnalyzer — 全功能分析（按需开关）
use face_core::FaceAnalyzer;
use face_core::inference::{DetectorKind, EngineConfig};

let mut config = EngineConfig::default();
config.detector_kind   = DetectorKind::Scrfd;  // 5 点对齐
config.enable_recognition = true;
config.enable_attributes  = true;
config.enable_gaze        = true;
config.enable_headpose    = true;
let mut analyzer = FaceAnalyzer::new(config)?;
let faces = analyzer.analyze(&image)?;
# 完整管线分析（SCRFD + 全部预测器）
./target/release/face <image_path>

# 机器可读 JSON 输出（基准对比）
./target/release/face <image_path> --bench

# 可视化结果输出为图片
./target/release/face <image_path> --render <output_dir>

# 示例集：单二进制 face-demo 含 15 个示例
./target/release/face_demo 01_detection
./target/release/face_demo 05_analyzer
./target/release/face_demo 15_mesh
# 1. 首次构建前下载模型权重（13 个 ONNX，约 223 MB）
python scripts/download_models.py

# 2. 构建（模型通过 include_bytes! 嵌入，产物无外部模型依赖）
cargo build --release

# 3. 运行测试
cargo test --workspace

# 可选：Android 构建（需 rustup + cargo-ndk + ANDROID_NDK_HOME）
./scripts/build_android.sh release
Cross-Platform

同一份代码，四大平台运行

Rust 的零成本抽象与 ONNX Runtime 的跨平台后端，让你在桌面与移动端复用同一引擎。

Windows

原生二进制，动态加载 onnxruntime.dll。

Linux

libonnxruntime.so，服务端 / 容器友好。

macOS

libonnxruntime.dylib，Apple Silicon / Intel。

Android

cargo-ndk 产出 .so，附设备侧基准工具。

Why face

为什么选择 face

🔒 零运行时依赖

模型在编译期内嵌，发布产物不再携带任何 .onnx 文件，部署更干净、更可控。

⚡ Rust 性能与安全

内存安全、无 GC、可预测延迟，适合边缘设备与高并发服务端推理。

🧩 统一且可裁剪

一个 EngineConfig 开关控制全部能力，按需启用以平衡体积与功能。

📦 多形态交付

核心库、命令行、示例集与 Android 工具齐备，开箱即用。

🌐 真正跨平台

桌面三端与 Android 共用同一份 Rust 代码与推理封装。

📄 宽松开源

以 MIT 许可证发布，自由用于商业与学术场景。
